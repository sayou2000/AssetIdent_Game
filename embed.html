<assettrace-game> Embed Demo

This page demonstrates both supported embed methods for AssetTrace: The Handover Quest. The game below runs in a sandboxed iframe with UTM tracking passed through, just like a real CMS embed. The iframe and Web Component are fully responsive.

↑ Method 1: responsive <iframe>

Method 2 — Web Component (optional)

For a cleaner API, drop in the tiny loader below and use <assettrace-game>. It reads utm attributes and posts events back to the parent page (e.g. for your analytics).

Embed Snippet (copy-paste)

<!-- Option A: iframe (recommended, universal) -->
<iframe
  src="https://<your-game-host>/index.html?utm_source=linkedin&utm_campaign=handover"
  title="AssetTrace: The Handover Quest"
  loading="lazy" allow="autoplay; fullscreen"
  style="width:100%;max-width:960px;height:480px;border:0;"
  allowfullscreen></iframe>

<!-- Option B: Web Component (cleaner API + event relay) -->
<script>
customElements.define('assettrace-game', class extends HTMLElement{
  connectedCallback(){
    const s=this.getAttribute('src')||'index.html';
    const p=['source','medium','campaign'].filter(k=>this.hasAttribute('utm-'+k))
      .map(k=>'utm_'+k+'='+encodeURIComponent(this.getAttribute('utm-'+k))).join('&');
    const f=document.createElement('iframe');
    f.src=s+(p?'?'+p:''); f.style='width:100%;height:480px;border:0;';
    f.loading='lazy'; f.allow='autoplay;fullscreen';
    this.appendChild(f);
  }
});
</script>
<assettrace-game src="https://<your-game-host>/index.html"
  utm-source="linkedin" utm-campaign="handover"></assettrace-game>

Replace <your-game-host> with your deployment URL (Coolify / Nginx / any static host). Game weighs < 200 KB — loads instantly.
